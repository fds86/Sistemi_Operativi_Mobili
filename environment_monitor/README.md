# Environment Monitor - Consegna progetto

Questo repository contiene i sorgenti del progetto Environment Monitor per ESP32.

## Contenuto principale
- Codice sorgente firmware: src/
- Librerie/moduli: lib/
- File di configurazione: include/
- Documentazione tecnica e report: docs/

## Allegati di consegna
- Archivio ZIP del progetto (sorgenti + documentazione)
- Report in PDF

## Tool usati
- PlatformIO
- ESP32 Arduino framework
- Doxygen (documentazione API)
- Pandoc (conversione report)
